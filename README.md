# Zomato Data Exploration & Analysis - SQL

## Project Overview
This project analyzes Zomato restaurant data using MySQL to explore restaurant ratings, pricing, cuisines, city-wise distribution, and online delivery services.

## Tools & Technologies
- MySQL
- SQL
- MySQL Workbench

## Key Analysis
- Identified top-rated restaurants.
- Analyzed restaurant distribution by city.
- Explored popular cuisines.
- Compared average costs across price ranges.
- Analyzed online delivery and table booking availability.

## SQL Concepts Used
- SELECT, WHERE, ORDER BY
- GROUP BY and HAVING
- Aggregate Functions
- CASE Statements
- Subqueries
- CTEs and Window Functions

## Project Files
- `zomato_queries.sql` — SQL queries used for data analysis.
- `zomato_restaurants.csv` — Restaurant dataset.
